# Task 002: Atomic UI Component Library & Layout Shell

## Objective
Construct the reusable atomic UI primitives and root navigation shell (Header, Navbar, Footer, Mobile Drawer) following the dark luxury design aesthetic.

---

## Action Items

- [ ] Construct atomic UI components in `src/components/ui/`:
  - `Button` (Primary gold fill, outline, ghost variants).
  - `Card` (Glassmorphic dark container).
  - `Input` & `Textarea` (Styled form controls with focus rings).
  - `Modal` (Accessible dialog wrapper with backdrop blur).
  - `Badge` (Dietary flag tags & event status pills).
- [ ] Build layout components in `src/components/layout/`:
  - `Header`: Navigation bar with brand logo, nav links, and "Reserve Table" primary action button.
  - `MobileDrawer`: Accessible navigation menu for mobile viewports.
  - `Footer`: Operating schedule, navigation sitemap, social placeholders, copyright notice.
- [ ] Verify accessibility across components (keyboard focus, touch targets > 44px).

---

## Deliverables & Acceptance Criteria
- Component library exported and ready for section composition.
- Mobile layout fully responsive at 375px viewport.
