# Task 004: Interactive Food & Drink Menu Page

## Objective
Develop the interactive menu page (`src/app/(public)/menu/page.tsx`) enabling patrons to filter dishes by category, filter by dietary requirements, search by keyword, and inspect item details.

---

## Action Items

- [ ] Build Category Filter Tabs (Starters, Main Courses, Desserts, Signature Cocktails, Fine Wines, Non-Alcoholic).
- [ ] Implement Search Bar for live keyword filtering across title and description.
- [ ] Implement Dietary Badges Filter (Vegan, Vegetarian, Gluten-Free, Chef Special).
- [ ] Build `MenuItemCard` presenting dish title, description, price placeholder, dietary tags, and high-res image.
- [ ] Build `DishDetailModal` for detailed ingredient view.
- [ ] Inject JSON-LD `@type: FoodMenu` schema.

---

## Deliverables & Acceptance Criteria
- Instant client-side filtering without full page reloads.
- Responsive menu grid supporting mobile (1 column) and desktop (3 columns).
