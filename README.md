# Sokem Bar & Restaurant

> Haute Gastronomie, Artisanal Cocktails & Live Jazz in Addis Ababa, Ethiopia.

A modern, high-performance, accessible, and responsive full-stack web application built for Sokem Bar & Restaurant.

---

## 🌟 Key Features

- **Luminous Warm Luxury Aesthetics**: Dark luxury palette with warm amber glow, translucent glass cards, and fluid Framer Motion animations.
- **Interactive Food & Cocktail Menu**: Live keyword search, sliding category tabs, dietary filter tags (*Vegan*, *Gluten-Free*, *Chef Special*), and dish detail modals.
- **Online Table Reservations**: 3-step concierge booking system (party size, date & time slot selection, guest dossier) with instant confirmation codes.
- **Events & Live Music**: Showcase of upcoming jazz nights, wine tasting dinners, and special gatherings.
- **Visual Atmosphere Gallery**: Categorized photo exhibition with full-screen keyboard-navigable Lightbox modal.
- **Location & Inquiries**: Real Addis Ababa phone connection (`093 001 4033`) and direct Google Maps shortcut with interactive preview.
- **Management Operations Portal**: Staff dashboard with live menu stock availability toggles and incoming reservation management.

---

## 🛠️ Technology Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React 18, Server Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Validation**: [Zod](https://zod.dev/)
- **Testing**: [Vitest](https://vitest.dev/)

## 🚀 Getting Started

### 1. Prerequisites
- Node.js 18+ or 20+
- npm or yarn

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/biluyb/Sokem-bar-and-restaurant.git

# Navigate to project directory
cd Sokem-bar-and-restaurant

# Install dependencies
npm install
```

### 3. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Running Unit Tests
```bash
npm run test
```

### 5. Production Build
```bash
npm run build
npm run start
```
